Obesity risk Analytics

This repository contains code and resources for analyzing obesity risk factors using various datasets. The analysis includes data preprocessing, statistical modeling, and visualization techniques to identify key contributors to obesity.

## Getting Started
To get started with the obesity risk analytics project, follow these steps:
unzip the dataset files provided in the `data` directory.
upload "obesity-analytics-notebooks" and "obesity-risk-analytics" individual folders to your google drive.

Clone the repository to your local machine or Google Colab environment.
1. notebooks contains phase-1
2. notebooks-forecasting contains phase-2

Note:
All notebooks inside notebooks and notebooks-forecasting folder are designed to be run in Google Colab for ease of use in an end-to-end manner.

Notebooks inside the folder "data" contains raw notebooks, data preprocessing scripts and raw datasets used for analysis.

Notebooks contained in notebooks and notebooks-forecasting folder are finalm self-explanatory with comments and markdown cells to guide you through the analysis process.
